# Сертификаты

Каталог для дополнительных корневых сертификатов, которых нет в системном
хранилище базового образа — например, УЦ Минцифры РФ.

Файлы `*.crt` и `*.pem` не коммитятся (см. `.gitignore`): сертификат получает
тот, кто разворачивает бота.

## Docker

Положите `.crt` в этот каталог. При сборке он копируется в
`/usr/local/share/ca-certificates/extra/`, и `update-ca-certificates`
регистрирует его на уровне ОС — это покрывает все исходящие соединения,
включая запросы к API MAX.

Если каталог пуст, сборка проходит штатно: `update-ca-certificates` в этом
случае ничего не делает.

## Без Docker

Укажите путь к PEM-файлу в переменной `MAX_CA_BUNDLE` — бот подключит его к
SSL-контексту aiohttp:

```bash
MAX_CA_BUNDLE=/path/to/russian-trusted-root-ca.pem
```

Отличие от способа с Docker: `MAX_CA_BUNDLE` действует только на соединения
самого бота, системные утилиты внутри контейнера про этот сертификат не знают.

Скачать сертификаты Минцифры: https://www.gosuslugi.ru/tls
